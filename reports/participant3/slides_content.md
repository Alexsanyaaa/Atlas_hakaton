# Материал участника № 3 для защиты

## Слайд: метод и фактический запуск

Русский BERT-энкодер + token-classification head, условие на конкретный атрибут. Каталожные значения применяются только при подготовке слабой span-разметки, не подаются модели. Реальный CPU-пилот: ruBERT-tiny2, 203 train / 99 dev окон, 104 optimizer steps, 139.4 сек. Проверено изменение параметров энкодера и загрузка checkpoint. Дополнительно выполнен частичный CPU-пилот ruBERT-base: два последних слоя + head; полное обучение остаётся для GPU.

## Слайд: результат и границы вывода

Exact span-F1 на выбранном silver dev: 0.037 → 0.596; precision 0.546, recall 0.657, support 99. Это НЕ gold-качество каталога и НЕ сравнение с CRF/rules. Недостаточно RAM/storage/screen примеров; только положительные условные пары. Есть ложные бренды и неполные модели. Автопринятие выключено, требуются semantic grounding и ручной gold. Тест не использовался.

## Дополнение для основного ruBERT-base

Частично дообучен: 107 train / 51 dev окон, 216 optimizer steps, 280 секунд CPU, 14,18M обучаемых из 177,72M параметров. Silver exact span-F1 0.333, precision 0.28; слабые brand/model и недостаточная разметка. Другая подвыборка и замороженные слои не позволяют объявить tiny2 лучше base по сравнению этих двух цифр. Полный GPU-прогон и human gold ещё нужны.
