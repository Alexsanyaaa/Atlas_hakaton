# Установка окружения и запуск обучения на Radeon RX 9070 XT

Для Windows 11 и Radeon RX 9070 XT. Окружение: WSL2, Ubuntu 24.04, Python 3.12, ROCm 7.2.1, ROCDXG 1.2.0, PyTorch 2.9.1.

Python и Bash в самой Windows устанавливать не нужно. Python устанавливается внутри Ubuntu, Bash входит в её стандартное окружение. Команды ниже выполняйте по порядку, обращая внимание на указанный терминал.

Нужен полный архив `transformer_rx9070xt_demo.zip` из чата: в нём находятся данные, настройки и скрипты. Одного файла `train_transformer.py` недостаточно. Для установки пакетов и первого скачивания модели требуется интернет.

## 1. Драйвер видеокарты — в Windows

Для подготовленного окружения используем AMD Adrenalin 26.2.2 в связке с ROCm 7.2.1. Установите соответствующий драйвер для своей видеокарты по официальной инструкции AMD и перезагрузите компьютер:

https://rocm.docs.amd.com/projects/radeon-ryzen/en/latest/docs/install/installrad/wsl/howto_wsl.html

Скрипт проекта не устанавливает Windows-драйвер. Linux-драйвер дисплея или DKMS внутри WSL отдельно устанавливать не нужно: скрипт устанавливает компоненты ROCm и ROCDXG для вычислений.

## 2. Установка WSL и Ubuntu — в PowerShell

Откройте PowerShell от имени администратора: меню «Пуск» → PowerShell → «Запуск от имени администратора».

Если Ubuntu 24.04 ещё не установлена, выполните:

```powershell
wsl --install -d Ubuntu-24.04
```

Перезагрузите компьютер, если система попросит. Затем снова откройте PowerShell и выполните:

```powershell
wsl --update
wsl -l -v
```

У `Ubuntu-24.04` в столбце `VERSION` должно быть `2`. Если указано `1`, выполните:

```powershell
wsl --set-version Ubuntu-24.04 2
```

Если Ubuntu 24.04 уже установлена, повторная установка не нужна. Не удаляйте существующие дистрибутивы.

Запустите Ubuntu:

```powershell
wsl -d Ubuntu-24.04
```

При первом запуске создайте имя пользователя Linux и пароль. Этот пароль потребуется для команд `sudo`. Символы при вводе пароля не отображаются — это нормально.

Официальная инструкция Microsoft:

https://learn.microsoft.com/en-us/windows/wsl/install

## 3. Python, Bash и базовые инструменты — внутри Ubuntu

Все дальнейшие команды выполняются в терминале Ubuntu, а не в PowerShell.

```bash
sudo apt update

sudo apt install -y \
  bash \
  coreutils \
  python3 \
  python3.12 \
  python3.12-venv \
  python3-pip \
  python3-setuptools \
  python3-wheel \
  wget \
  ca-certificates \
  unzip
```

Введите пароль пользователя Ubuntu, если потребуется.

Проверьте версии:

```bash
bash --version
python3 --version
python3.12 --version
```

Python должен показывать `3.12.x`. Установщик проекта рассчитан именно на Ubuntu 24.04 с Python 3.12.

## 4. Перенос проекта в Ubuntu

Скачайте `transformer_rx9070xt_demo.zip` из чата на этот ПК в папку «Загрузки» Windows. В примерах ниже это `C:\Users\ВАШЕ_ИМЯ\Downloads`.

Замените `ВАШЕ_ИМЯ` на настоящее название папки пользователя Windows. Оно может отличаться от отображаемого имени учётной записи. Если архив сохранён в другой папке, укажите её фактический путь.

Выберите только один способ переноса: A или B.

### Способ A: распаковать архив прямо из Ubuntu

```bash
unzip "/mnt/c/Users/ВАШЕ_ИМЯ/Downloads/transformer_rx9070xt_demo.zip" \
  -d "$HOME/transformer_rx9070xt_demo"

cd "$HOME/transformer_rx9070xt_demo"
```

Например, если папка пользователя Windows называется `Alex`:

```bash
unzip "/mnt/c/Users/Alex/Downloads/transformer_rx9070xt_demo.zip" \
  -d "$HOME/transformer_rx9070xt_demo"

cd "$HOME/transformer_rx9070xt_demo"
```

### Способ B: скопировать уже распакованную папку

Если вы уже распаковали архив в Windows в `Downloads/transformer_rx9070xt_demo`, выполните:

```bash
cp -r "/mnt/c/Users/ВАШЕ_ИМЯ/Downloads/transformer_rx9070xt_demo" "$HOME/"

cd "$HOME/transformer_rx9070xt_demo"
```

Команды рассчитаны на первый перенос в новую папку. Если в Linux уже есть папка с результатами обучения, не распаковывайте поверх неё новый архив.

Проверьте файлы:

```bash
ls
python3 verify_training_bundle.py
```

В текущей папке должны быть `train_transformer.py`, `check_gpu.py`, `verify_training_bundle.py`, `scripts`, `configs`, `src` и `data`. Проверка должна завершиться успешно. Она работает на стандартном Python, без предварительной установки библиотек проекта.

## 5. Установка ROCm, PyTorch и остальных библиотек

Находясь в папке проекта внутри Ubuntu, выполните:

```bash
bash scripts/setup_rx9070xt_wsl.sh
```

Скрипт автоматически:

- устанавливает ROCm 7.2.1 и ROCDXG 1.2.0;
- создаёт Python-окружение `.venv-wsl` в папке проекта;
- устанавливает официальную сборку PyTorch 2.9.1 для ROCm 7.2.1 и Triton;
- устанавливает Transformers 4.57.6, NumPy 1.26.4, Safetensors, PyYAML и их зависимости;
- проверяет целостность комплекта и вычисления с обратным распространением ошибки на GPU.

Вручную повторять установку этих библиотек не нужно. Скрипт запросит пароль для `sudo`, если потребуется. Дождитесь завершения установки.

Успешное завершение:

```text
Ready. Train with: bash scripts/run_rx9070xt_wsl.sh
```

Проверка GPU должна показывать вашу Radeon, непустое значение `hip` и:

```text
"fp16_backward": "PASS"
```

PyTorch использует имя `cuda` для API устройства и на AMD через HIP. Поэтому `device: cuda` в конфигурации проекта корректно для этой Radeon.

Чтобы отдельно повторить проверку GPU:

```bash
cd "$HOME/transformer_rx9070xt_demo"
source scripts/rocm_wsl_env.sh
.venv-wsl/bin/python check_gpu.py
```

## 6. Запуск обучения

```bash
cd "$HOME/transformer_rx9070xt_demo"
bash scripts/run_rx9070xt_wsl.sh
```

Первый запуск скачает исходную модель `ai-forever/ruBert-base`, подготовит обучающие примеры и начнёт обучение. Скрипт запуска сам использует `.venv-wsl`: вручную активировать окружение не требуется.

Тестовая конфигурация ограничена 1200 шагами и мягким лимитом 6 часов обучения. Скачивание, подготовка данных, проверка и сохранение могут добавить время. Скорость на RX 9070 XT в рамках подготовки комплекта не измерялась; срок менее суток не гарантирован.

Лучший сохранённый чекпоинт:

```text
models/rx9070xt_demo/checkpoint
```

Для переноса обученной модели нужна вся папка чекпоинта, включая настройки и токенизатор.

После обучения показать предсказания на демонстрационных карточках:

```bash
bash scripts/run_rx9070xt_wsl.sh predict
```

Это тестовый вариант: обучение использует автоматически подготовленную разметку. Качество на такой разметке не заменяет проверку на вручную размеченных карточках.

## 7. После перезагрузки ПК

Устанавливать пакеты заново не нужно.

В PowerShell откройте Ubuntu:

```powershell
wsl -d Ubuntu-24.04
```

Внутри Ubuntu перейдите в проект и запустите демонстрацию:

```bash
cd "$HOME/transformer_rx9070xt_demo"
bash scripts/run_rx9070xt_wsl.sh predict
```

Повторный запуск обучения в уже заполненную папку результатов может быть отклонён конфигурацией, чтобы сохранить существующий чекпоинт. Не удаляйте его для запуска демонстрации.

## Если что-то не запускается

**`python3: command not found` или `bash: command not found`:** убедитесь, что вы внутри Ubuntu, и выполните установку из шага 3. Приглашение PowerShell обычно начинается с `PS`; в Ubuntu обычно выглядит как `имя@компьютер:...$`.

**`No such file or directory` при переносе архива:** проверьте настоящее имя папки пользователя Windows, место сохранения архива и его название. В WSL диск `C:` доступен через `/mnt/c`.

**`/dev/dxg is missing`:** проверьте драйвер AMD в Windows и версию WSL. В PowerShell выполните `wsl -l -v`: у Ubuntu должна быть версия `2`. После установки драйвера перезагрузите Windows и снова откройте Ubuntu.

**Ошибка целостности комплекта:** заново перенесите исходный архив в отдельную новую папку. Не обходите проверку и не перезаписывайте папку с готовой моделью.

**Ошибка нехватки видеопамяти во время обучения:** в `configs/rx9070xt_demo.yaml` уменьшите `batch_size` и `eval_batch_size` с `12` до `6`. Для сохранения прежнего эффективного размера обучающего батча увеличьте `gradient_accumulation` с `2` до `4`.

При другой ошибке сохраните её полный текст вместе с командой, после которой она появилась.
