# Полное обучение ruBERT на RX 9070 / RX 9070 XT, 16 ГБ

Используется уже установленное окружение WSL2 Ubuntu 24.04 и ROCm. Если демонстрационное обучение успешно завершилось, повторно устанавливать библиотеки не нужно.

## Что здесь означает «полное»

Весь подготовленный набор: 157 718 обучающих пар текст/характеристика и 19 005 проверочных пар, до 394 характеристик. Исходный срез содержит 39 999 товаров. Это НЕ обучение на всех товарах исходного каталога: для него потребуется отдельная подготовка данных.
На
Тестовая часть остаётся отложенной. Разметка всё ещё автоматическая: увеличение объёма само по себе не исправляет найденные ошибки с отсутствующими и многозначными характеристиками.

Новый запуск начинает дообучение с исходного ruBERT, а не продолжает демонстрационный чекпоинт. Демо-веса сохраняются в своей папке. Здесь нет восстановления оптимизатора после прерывания.

## Перенос настроек

Скачайте transformer_rx9070_full_settings.zip из чата в Windows Downloads. Архив содержит новые настройки, скрипт запуска, обновление тренера с расчётом числа шагов, обновлённый список проверяемых файлов и эту инструкцию; данные уже находятся в вашем проекте. Файлы скриптов и манифеста нужно заменить при распаковке. Веса и данные не перезаписываются.

Внутри Ubuntu, заменив ВАШЕ_ИМЯ на папку пользователя Windows:

```bash
cd "$HOME/transformer_rx9070xt_demo"
unzip -o "/mnt/c/Users/ВАШЕ_ИМЯ/Downloads/transformer_rx9070_full_settings.zip" -d .
bash scripts/run_rx9070xt_full_wsl.sh
```

Либо после распаковки всего обновления запустите существующий скрипт:

```bash
cd "$HOME/transformer_rx9070xt_demo"
bash scripts/run_rx9070xt_wsl.sh --config configs/rx9070xt_full.yaml
```

## Настройки

- 3 эпохи: три прохода по обучающим окнам текста.
- FP16 и экономия видеопамяти при обучении.
- 8 примеров за один проход; обновление параметров после трёх проходов, эффективный батч — 24.
- Максимальная длина входа — 256 частей текста; длинные тексты разбиваются на перекрывающиеся окна.
- Сохранение последнего состояния каждые 1000 шагов.
- Проверка качества каждые 2000 шагов и в конце каждой эпохи; лучший вариант хранится отдельно.
- Лимит времени — мягкие 22 часа, чтобы оставить запас до суток. Подготовка, скачивание, проверка и сохранение могут увеличить общую длительность; завершение за сутки не гарантировано.
- 100 000 шагов — технический верхний предел, а не плановое число шагов. Обучение завершается после трёх эпох или раньше по ограничению времени/шагов. Ранняя остановка по отсутствию улучшения для этого запуска практически отключена.
- Все подготовленные пары выбираются без ограничения 30 000. Лимиты окон подняты до 1 000 000. Фактическое число пригодных окон выводится после подготовки; очень большой объём может потребовать дополнительной оперативной памяти.

После подготовки строка features_ready покажет train_windows и step_limit — фактический план шагов на три эпохи. Он вычисляется так: сначала округлите train_windows / 8 вверх, затем разделите на 3 и снова округлите вверх, затем умножьте на 3 эпохи. При срабатывании временного лимита шагов будет меньше. Обновлённый тренер использует этот план в estimated_remaining_seconds. Прогноз приблизительный: будущие проверки и сохранения могут добавить время.

## Результаты

```text
models/rx9070xt_full/checkpoint           — лучший вариант по dev
models/rx9070xt_full/checkpoint-last      — последние сохранённые веса
models/rx9070xt_full/best_metrics.json    — метрики лучшего варианта
models/rx9070xt_full/training_summary.json — число шагов и причина остановки
```

Это сохранённые веса для предсказаний, а не комплект для точного продолжения прерванного обучения.

После завершения:

```bash
bash scripts/run_rx9070xt_wsl.sh predict --checkpoint models/rx9070xt_full/checkpoint
```

Для сравнения с демонстрационным вариантом используйте одни и те же вручную размеченные карточки. Автоматические dev-метрики нового и старого запусков напрямую сравнивать нельзя: изменены объём проверки и набор характеристик.

## При нехватке видеопамяти

В configs/rx9070xt_full.yaml измените:

```yaml
batch_size: 4
eval_batch_size: 4
gradient_accumulation: 6
```

Эффективный обучающий батч останется 24. После уже начавшегося обучения для нового запуска укажите новую папку output, например models/rx9070xt_full_retry. Не удаляйте прежние чекпоинты.

## Во время работы

ПК должен быть подключён к питанию и оставаться включённым. Не закрывайте терминал обучения. Если Windows уходит в сон, обучение приостанавливается; предварительно проверьте свои настройки питания. По GPU может выполняться только один тяжёлый тренировочный запуск, чтобы не конкурировать за видеопамять.

Скорость и максимальный расход памяти на вашей RX 9070 в этом полном режиме пока не измерены. GPU-проверка выполняется перед запуском.
